# صفحة هبوط عربية لإنشاء QR Code

## الملفات
- `index.html`: محتوى الصفحة باللغة العربية واتجاه RTL.
- `style.css`: تصميم متجاوب للهاتف والحاسوب.
- `script.js`: التحقق من الرابط، إنشاء QR، وتنزيله بصيغة PNG.

## التشغيل محليًا
افتح `index.html` في متصفح حديث مع اتصال بالإنترنت؛ تُحمّل مكتبة QRCode.js وخط Cairo من CDN.

## النشر مجانًا
### GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات الثلاثة إلى جذر المستودع.
3. افتح Settings ثم Pages.
4. اختر النشر من الفرع الرئيسي (main) ومجلد الجذر (root).
5. احفظ وانتظر ظهور رابط الموقع.

يمكنك أيضًا نشر الملفات على Netlify أو أي استضافة صفحات ثابتة.

## ملاحظات
- المولّد ينشئ QR ثابتًا يحتوي على الرابط نفسه، وليس QR ديناميكيًا.
- الرابط يُعالج داخل المتصفح ولا يُرسل إلى خادم خاص بك.
- تحتاج الصفحة إلى الإنترنت لتحميل المكتبة والخط من CDN.
- اختبر الرمز بكاميرا هاتف قبل الطباعة.
- لا تتضمن الصفحة نظام حسابات أو إحصاءات مسح.
